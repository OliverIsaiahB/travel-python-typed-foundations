# Python & Typed Data Foundations

A from-scratch beginner project that teaches Python's type hints, dataclasses, and the filter/score/sort patterns that power every recommendation engine. The anchor is a tiny "travel listing" model you score against a traveler's preferences — the exact shape you will grow into a real recommendation platform later in the journey.

## Stack
- Python
- type hints
- dataclasses
- Enum
- typing
